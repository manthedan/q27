# f16-accumulate MMA probe — BaseRT survey import #1

Status: PRE-REGISTERED before measurement (results appended below).
Parent: 2026-07-16-basert-survey-draft.md §probe 1 (yukon, survey-only) —
BaseRT's default quantized simd_gemm is f16×f16+f16 8×8 MMA with f32acc
as the exception variant; q27's chunk GEMM accumulates f32. Prefill is
MMA-issue-bound (roofline: C/Beq 1.135, one unpack round landed; direct-
RHS and barrier-free both parked), so an accumulator-pressure reducer is
squarely at the measured bottleneck. Margin-aware note: this is a
reopened lever of exactly the class the L1–L5 contract repriced —
byte-identity is NOT the gate; the GEMM-class envelope is.

## Probe

New roofline arm F: `q27_mma_roofline_f` = the production
`q27_matmul_t2_mm_h` body with `simdgroup_half8x8` accumulators (and a
half flush tile). Everything else identical: same operands as arm C
(packed T2 bytes, int8 activations + per-32 float scales), same 32×16
tile, 64-K walk, byte-LUT staging, per-64-slab flush. The f16 sums live
only within one 64-K slab (bounded by 64·127·2 = 16,256 — inside half
range, outside half integer-exactness at 2^11); the scale-fold and
cross-slab accumulation stay f32 in `racc`, unchanged.

Harness: `tools/metal_mma_roofline.cpp` gains the arm (8 arms ⇒ TRIALS
16, t-crit 2.131 @15 dof, rotation counterbalance preserved by the
static_assert). Correctness gate before timing: F vs C max relative
difference ≤ 5e-2 on all live outputs (f16 slab rounding is real error,
not a bug — the measured value is itself a probe read), non-finite
rejected, zero-poison anti-vacuity as for every arm.

## Pre-registered reads (BaseRT-draft kill line, adopted verbatim)

- **Graduate** (build the production trial behind a
  `Q27_METAL_GEMM_F16ACC` knob + envelope pair run): chunk-aggregate
  C/F LOWER 95% CB ≥ 1.10.
- **Park with numbers**: C/F UPPER CB ≤ 1.10 — accumulator register
  pressure is then not the M4 MMA issue limiter (consistent with the A
  arm already sitting near C after staging costs).
- Straddle: report inconclusive, extend trials once before parking.
- Numerics read (secondary): the F-vs-C max rel diff per shape. If it
  exceeds 5e-2 the gate FAILS the probe outright — that would say f16
  slab sums are not envelope-viable regardless of speed, and the
  graduate path dies even on a perf win.

Perf verdict comes from the bench arm alone; NO production route change
in this probe. If graduated, the production trial is its own
pre-registered step with the envelope instrument (`--envelope` gains the
acc-class pair) before any default flips.

## Results (appended post-measurement, same afternoon, M4 16 GB)

**PARKED by the pre-registered kill line.** x_rows 96, 8 reps × 16
interleaved trials, rotation counterbalanced:

- **Aggregate C/F = 1.065 [1.064, 1.066]** — upper CB ≤ 1.10. A real
  6.5% kernel win exists, but accumulator width is not the M4 MMA issue
  limiter. Per-shape ratios are flat (1.053–1.067) — no shape-dependent
  exception to rescue.
- Consistent mechanism picture: Beq/A (staging/barrier cadence residual)
  re-measured at 1.276 — the residual cost lives in the staging
  machinery, which the K=128, R3, and direct-RHS probes have each
  independently shown is not harvestable on M4's occupancy budget.
  BaseRT's f16-acc default is presumably right on THEIR unstaged loop
  shape; on q27's staged 64-K walk the accumulators are not the
  pressure point.
- **Numerics caveat (recorded so this is never miscited):** F-vs-C max
  rel diff measured exactly 0 on every shape — the synthetic bench
  operands keep 64-slab sums inside f16's integer-exact range, so the
  5e-2 gate was never stressed. This probe says nothing about f16-acc
  error on real activations; if the lever is ever reopened (e.g. M5
  cooperative tensors change the staging economics), the envelope pair
  run is still mandatory.
- **Bonus read — C/Beq drift:** 1.082 [1.081, 1.082] vs 1.135 before
  the byte-LUT round. The one authorized unpack round harvested the
  plumbing gap down to the 1.08 maturity line (verdict line: "permit
  exactly ONE targeted kernel round" — that round has already been
  spent). Prefill-MMA MATURE stands with the remaining gap at the line
  itself. C/Cx also re-read at 1.022 (still under every action line).
