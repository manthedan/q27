# A5: KL(mixed ‖ official) cross-model paired-logit gate — pre-registration (2026-07-18)

Review-2 (2026-07-18-expert-review-2-triage.md §1, §8) adopted the A0–A7
sequence. A5 is the decisive quality gate for the mixed-pack serving thesis:
**KL(mixed ‖ official 17 GiB) < KL(T2 ‖ official)** must hold on the
pre-registered corpora, or the mixed pack's NLL recovery is not translating
into distribution-level fidelity against the model we would actually ship
against.

## Why a new driver

`--kl-kv` is a same-model KV-precision comparator: one `Shared` mapping,
two engines that differ only in the KV store path, lockstep teacher-forced.
A5 is **cross-model**: two independent artifacts (mixed pack and official),
each with its own `Model` mapping, `MetalBackend` queue, weight wrap, and
residency set. The lockstep machinery (12-token `teacher_force_logits`
chunks, per-position `q27::forward_kl` on CPU in double precision, bucketed
report) is reused unchanged; only the engine-construction half changes.

The tokenizer is byte-identical across all tiers (verified: the same
`models/qwen36-27b-mtp/qwen36-27b-mtp.tok` loads every artifact in the
census and serving stacks). No cross-tokenizer alignment is needed; position
`i` in model A's stream corresponds to position `i` in model B's.

## Driver shape

New top-level CLI flag, rides the `--nll FILE --nll-long N` input path:

```
q27-metal-cli --kl-pair MODEL_A MODEL_B --nll tokens.bin --nll-long 8192 \
              --tokenizer models/qwen36-27b-mtp/qwen36-27b-mtp.tok \
              --ctx 8192
```

- Two `MetalEngine::Shared` mappings opened in the same process:
  `open_shared(MODEL_A)` and `open_shared(MODEL_B)`.
- One engine per mapping, both fp16-KV (the KL is a *weight* comparison;
  the KV codec is held at the cleanest setting so it cannot confound).
- Both engines advance in lockstep over the same token stream in
  12-token chunks; per-position forward-KL is computed on CPU in
  double precision exactly as `--kl-kv` does.
- Positions must match across engines: chunk boundaries identical,
  `teacher_force_logits` calls paired, no resets.

Mutual exclusions: `--kl-pair` is its own instrument. Drop `--kl-kv*`,
`--kv`, `--chunk-parity`, `--envelope`, `--save-state`, `--load-state`,
`--tokens`, `--prompt`, `--validate-only`, `--dump-logits`,
`--temperature/--top-p/--top-k/--seed`, `--mtp/--suffix/--oracle`,
`--prefill`.

## DESIGN AMENDMENT (2026-07-18 evening, operator-approved): sequential two-pass replaces the yukon port

The yukon CUDA port was scoped purely for measurement. Cheaper equivalent
that stays on the M4: teacher forcing is deterministic per model, so the
two models never need to be resident simultaneously.

- **Pass 1 (baseline alone):** new `--logits-dump FILE` mode rides the
  `--nll FILE --nll-long N` path, teacher-forces the corpus, and streams
  every position's f32 logits row to FILE in chunk order (no header; row
  i = position i, VOCAB=248320 f32 per row). Official 17 GiB runs alone —
  fits (validated: `--kl-kv-self` on official runs at 1.03 pos/s).
- **Pass 2 (each candidate alone):** new `--kl-vs-dump FILE` mode
  teacher-forces the same stream through the candidate, mmaps FILE
  chunk-by-chunk, and computes per-position `forward_kl` exactly as
  `--kl-pair` does — same buckets, tail, runs, `--kl-pair-out` per-position
  dump for the bootstrap.

Mathematically identical to lockstep: position i's logits depend only on
the prefix, and run-to-run bit-determinism is already established (the
NLL identity anchors reproduce EXACTLY across runs/processes on this
stack). Bonus: one official dump serves every current and future
candidate without rerunning the expensive model.

Corpus length: 4K positions both corpora first as a fast read (~2.5 GB
dumps, ~30-35 min official pass each); 8K only if the 4K result lands in
the conditional band (operator call, 2026-07-18).

Gates (replacing the residency-based G2/G3):
- G2': candidate vs ITS OWN dump = 0.0 exactly at every position
  (plumbing: dump format, mmap alignment, chunk order).
- G3': M1 vs B1 dump must reproduce the lockstep number on the same
  corpus slice (we have `--kl-pair` M1-vs-B1 at 99 pos: 0.0266966 mean,
  max 0.112171 @pos 78 — must match to the printed digits).

## Pre-registered gates

### Plumbing gates (must pass before any measurement)

- **G1 (unit):** `forward_kl` unit battery — KL(p,p) = 0, KL ≥ 0,
  agreement with naive softmax reference, asymmetry sanity. (Already
  exists from `--kl-kv`; must still pass.)
- **G2 (self-KL plumbing):** `--kl-pair MODEL MODEL --nll tokens.bin
  --nll-long 256` must produce KL = 0.0 exactly at every position
  (two engines on the *same* mapping, one fp16 each, lockstep — any
  nonzero means position/chunk misalignment, not numerics). Hard stop
  on nonzero.
- **G3 (sabotage both ways):** two controls must give the expected
  sign:
  - `--kl-pair T2 T2` → KL = 0 (plumbing, same as G2 but on a real
    tier artifact).
  - `--kl-pair T2 B1` → KL > 0 at every position (two different
    models; a zero here means the driver is not actually reading the
    second artifact).

### Measurement gate (the ship/kill line)

Run on the standing 8K wikitext NLL corpus **and** on an 8K held-out
code corpus (A4's code requirement folded in per the operator's call):

```
--nll data/wikitext-2-raw-8k.tokens --nll-long 8192
--nll data/code-holdout-8k.tokens    --nll-long 8192
```

For each corpus, three runs:

1. `KL(T2 ‖ official)` — reference
2. `KL(mixed ‖ official)` — candidate
3. `KL(B1 ‖ official)` — floor

**Ship line:** `KL(mixed ‖ official) < KL(T2 ‖ official)` on BOTH
corpora, with the per-position paired bootstrap 95% CI on
`KL(mixed) − KL(T2)` excluding 0 from below.

**Conditional:** the CI includes 0, or the ordering holds on only one
corpus — report, the operator decides.

**Kill:** `KL(mixed ‖ official) ≥ KL(T2 ‖ official)` on either corpus
with CI excluding 0 from above — the mixed pack's NLL recovery is not
translating into distribution-level fidelity; the A1/A2 lone-arm
recoveries are endpoint-overshoot artifacts (R2's WiSE-FT/task-
arithmetic caveat) and the mixed-pack serving thesis closes.

### What we do NOT claim

A KL win here does not prove the mixed pack is *better* than T2 in
absolute terms — only that it is closer to the official 17 GiB
reference than T2 is. The capability battery (A6) remains the
conjunctive gate.

## Implementation notes

- `--kl-pair-self MODEL` is the G2 plumbing arm (same mapping, two
  fp16 engines). Reuses the `--kl-kv-self` internals where possible;
  the flag exists so the plumbing gate does not require two mappings.
- Bucketed report: same edges as `--kl-kv` (0–2k / 2k–8k / 8k–16k /
  16k–32k) plus overall mean, tail quantiles (p50/p90/p99/p99.5/max),
  and run-length structure at 0.1/0.5 nats — the tail is the
  graduation metric, not the mean (kv-codec step-1 finding).
- The paired bootstrap CI lives in a small post-processor (Python or
  awk) over the per-position KL dump; the driver writes
  `--kl-pair-out FILE` with one KL per line per position for each
  corpus × arm.

## Non-goals

- On-policy KL (own generations), sub-2-bit KV experiments, GPU KL
  reduction, CUDA parity — all follow-ups, same as `--kl-kv`.
- This does NOT replace the NLL census publication or the capability
  battery; it is the third leg of the A5/A6 conjunctive gate.

## Amendment (2026-07-19): A5 on `gdn_pair` — pre-registration

**Why this arm exists.** The rescue (`2026-07-18-gdn-pair-rescue.md`)
exonerated the `gdn_pair` PACK: its ship-gate probe failure was a
serving-binary artifact, not a graft pathology. That removes the reason
`gdn_pair` was ruled A5-ineligible — but does NOT touch the reason the
mixed thesis died (cheap_pair's A5 KILL). `gdn_pair` is the ONE mixed arm
whose profile is qualitatively different: it **beat all-T2 on NLL**
(0.9925) where cheap_pair only recovered 48% of the gap. If KL tracked
NLL it would pass; A5 exists precisely because it does not. This
measurement is therefore decisive rather than confirmatory — the single
arm that could reopen the thesis.

**Subject (frozen).** `gdn_pair` = B1 base + T2 `attn_qkv` (all blocks) +
T2 `ssm_alpha`/`ssm_beta` (all blocks), built locally with
`tools/q27_mix.py --take '(attn_qkv|ssm_(alpha|beta))\.weight'`. Expected
md5 `107647e9cba0f01a003934011644c2fe` (byte-identical to the mini's
exonerated pack); the build is verified against this md5 before any
replay.

**Baselines regenerated, both arms re-run (house rule).** The Jul 17
official dumps are HEADERLESS and the current `--kl-vs-dump` hard-rejects
them (Q27LDMP1 magic + token_hash binding, autoreview P1). Regenerating
the dumps with the CURRENT binary changes the official reference's own
decode path, so the Jul 17 T2/M1 numbers are NOT comparable to new
replays. Therefore BOTH the official dumps AND the T2 baseline are
regenerated fresh under one binary, and the gdn_pair verdict is computed
against THIS T2 run — never borrowed from Jul 17. (The M1 arm is not
re-run; its thesis is already closed.) Old artifacts are preserved
untouched in `logs/kl-pair-20260718/`; new artifacts go to
`logs/kl-pair-20260719/`.

**Protocol (identical to A5).** `--nll-long 4096` → 4095 teacher-forced
positions; corpora `data/wikitext2-test.tokens.bin` and
`data/codeparrot-python-2mb.tokens.bin`; fp16 KV; one resident model at a
time (serial passes). Per-position KL written via `--kl-pair-out`.

**Gate (both corpora, conjunctive).** For each corpus compute the paired
per-position difference d_i = KL(gdn_pair_i ‖ official_i) −
KL(T2_i ‖ official_i) over the 4095 shared positions. The gate CLEARS on
a corpus only if mean(d) < 0 AND the one-sided 95% upper confidence bound
from 10,000 fixed-seed (1729) contiguous-256-token block-bootstrap
resamples of the mean-d is < 0. **SHIP-reopen requires clearing BOTH
corpora.**

**Kill / verdict lines.**
- **REOPEN:** both corpora clear → the mixed-pack thesis is NOT dead for
  the NLL-strongest arm; record and re-rank (A6/product gates would be
  the next conjunctive requirement, separately funded).
- **KILL (expected):** either corpus has mean(d) ≥ 0 or its 95% UCB ≥ 0
  → the endpoint-overshoot / rotate-away-from-official pattern holds for
  the NLL-strongest arm too; the mixed-pack serving thesis is closed
  permanently and the two-tier ladder (B1 small, T2 quality) stands.
  Prior is strongly negative: cheap_pair rotated away on both corpora
  (+0.046 wikitext, +0.175 code).

**Cost.** 6 serial passes × ~4–5 min ≈ 30 min on this M4 (2 official
dumps + 2 T2 replays + 2 gdn_pair replays), plus the bootstrap (seconds).
One transient 3.8 GiB pack, deleted after the replays. No new code — the
driver, header validation, and `--kl-pair-out` all exist and are gated.

### RESULTS (2026-07-19) — KILL on both corpora; the mixed-pack thesis is CLOSED

All 6 passes ran clean on this M4, serial, one resident model. The
gdn_pair pack md5-verified byte-identical to the exonerated pack
(`107647e9…`). The regenerated T2 baseline reproduced the Jul 17 numbers
EXACTLY (wikitext 0.749878 vs 0.7499; code 0.476571 vs 0.4766),
confirming the current binary's dump/replay path is stable and the
fresh-baseline pair is valid.

| corpus | KL(T2‖off) | KL(gdn‖off) | mean(d) | one-sided 95% UCB | boot<0 | verdict |
|---|---|---|---|---|---|---|
| wikitext | 0.749878 | 0.760094 | **+0.0102** | +0.0458 | 37.84% | **KILL** |
| code | 0.476571 | 0.651109 | **+0.1745** | +0.1940 | 0.00% | **KILL** |

The gate requires mean(d) < 0 AND UCB < 0 on BOTH corpora. Neither corpus
clears:

- **wikitext** is a near-tie (mean(d) +0.0102; 37.84% of bootstrap means
  dip below zero) — gdn_pair is essentially indistinguishable from T2
  against official, but NOT closer, and the gate demands *closer*. The
  NLL win (0.9925) does NOT translate into a KL win.
- **code** is a decisive rotation away from official (mean(d) +0.1745,
  0.00% below zero) — statistically identical to cheap_pair's +0.1753.

**Interpretation.** The NLL-strongest mixed arm fails A5 exactly as
cheap_pair did. This is the confirmation, on the strongest available
candidate, that the graft direction rotates the distribution AWAY from
the official 17 GiB reference even when it recovers — or beats — T2 on
NLL. The endpoint-overshoot mechanism the review-2 amendment flagged is
now demonstrated on BOTH mixed arms, on BOTH corpora. NLL-to-T2 and
KL-to-official measure different things, and on this family the graft
optimizes the former at the expense of the latter.

**Verdict: the mixed-pack serving thesis is permanently CLOSED.** The
rescue exonerated the pack (no agentic pathology); A5 now convicts the
approach (rotates away from official). There is no remaining mixed arm
with a qualitatively different profile left to test — gdn_pair was the
strongest. The two-tier ladder stands: **B1 = small tier, T2 = quality
tier.** A6/product gates are moot for all mixed packs.
