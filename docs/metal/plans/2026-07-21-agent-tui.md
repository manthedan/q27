# Native agent TUI — design note

**Status:** Phase 0–1 shipped; Phase 2 + 4 (tool cards, sticky multiphase footer, queue-while-busy) on `agent-tui`  
**Date:** 2026-07-21  
**Roadmap:** METAL_PROGRESS #3; `experiments/ds4-agent/README.md` port slice 8

## Goal

A real interactive front-end for `q27-agent` without rewriting the worker,
engine, tools, or persistence contracts. UI thread owns the terminal; worker
owns Metal.

## Inspiration

| Source | Take | Skip |
|--------|------|------|
| [antirez/ds4](https://github.com/antirez/ds4) `ds4_agent.c` | linenoise multiplex, status footer, tool visualizer, prompt queue, slash sessions | DSML, browser, distributed, wholesale 10k-line port |
| [pi coding-agent](https://github.com/earendil-works/pi/tree/main/packages/coding-agent) | layout (stream / editor / footer), slash discoverability, queue-while-busy UX | TypeScript, pi-tui runtime, extensions/npm packages |

**Stack choice:** native C + ds4-extended linenoise (status footer, nonblocking
feed). No Node, ncurses, or notcurses for v1.

## Module map

| File | Role |
|------|------|
| `third_party/linenoise/` | Vendored ds4 linenoise (BSD) |
| `q27_agent_tui.*` | Status formatting, TTY helpers, progress bar |

### `q27-tui` presentation (empty prompt)

| Key | Action |
|-----|--------|
| `t` | Toggle finished thinking expand/collapse (**default: collapsed**) |
| `T` | Cycle theme |
| `m` | Toggle markdown rendering |
| Esc / Ctrl-C | Cancel active turn |

Live open `<think>` always streams in full. Agent-side think budget:
`Q27_AGENT_MAX_THINK_TOKENS` (default off) — see packaging + ds4-agent READMEs.

## Non-goals (v1)

Browser tooling, session tree branching, pi extensions, JSONL session graph,
rewriting tool grammar or SNAP1.

## Gates
